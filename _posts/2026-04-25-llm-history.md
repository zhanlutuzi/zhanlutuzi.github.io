# 大模型的发展脉络

## 一句话总结

大模型的发展不是突然发生的，它大致经历了“深度学习兴起、Transformer 出现、预训练范式成熟、规模化能力显现、对话产品出圈、多模态和推理能力增强”这几步。

## 我一开始的问题

我最早问的是：

> 大模型的发展历程是什么？

这个问题看起来像是在要一份历史年表。但真正有用的不是记住每一年发生了什么，而是看懂大模型能力变化背后的几条主线。

## 第一阶段：深度学习先证明了“规模 + 数据”有用

在大模型之前，深度学习已经先在图像、语音、机器翻译等任务里证明了自己的价值。

这一步的重要性在于，它让大家相信：如果有足够多的数据、足够大的模型、足够强的计算资源，神经网络可以从数据中学出复杂规律，而不是完全依赖人工设计规则。

对我来说，这里要记住的不是某一个具体模型，而是一个方向的改变：

```text
人工设计特征
  -> 让模型从大量数据中自己学习特征
```

## 第二阶段：Transformer 让大规模训练变得更合适

2017 年的 Transformer 是关键节点。

在它之前，处理文本序列常用 RNN、LSTM 之类的结构。它们可以处理顺序信息，但并行效率不够理想。Transformer 用 Attention 机制处理序列中不同位置之间的关系，更适合大规模并行训练。

这就是为什么后来很多语言模型都会围绕 Transformer 发展。

这里我给自己的记忆句是：

> Transformer 不是第一个处理语言的神经网络，但它成了后来大模型最重要的架构底座。

## 第三阶段：BERT 和 GPT 让“预训练”成为主流范式

2018 年前后，BERT 和 GPT 代表了两条很重要的路线。

BERT 更偏理解任务。它通过双向上下文学习语言表示，然后在分类、问答、自然语言推理等任务上微调。

GPT 更偏生成任务。它用 Decoder-only Transformer 按顺序预测下一个 Token，这条路线后来成为对话式大模型的重要基础。

这一步的关键不是“BERT 和 GPT 谁更强”，而是预训练范式成熟了：

```text
先在大规模文本上学习通用语言能力
  -> 再通过微调、指令训练或对齐，让模型适应具体任务
```

## 第四阶段：GPT-3 展示了规模化能力

GPT-3 的重要性在于，它让更多人看到：当模型规模、数据规模和计算量继续增长时，模型会出现更强的少样本、零样本能力。

这时候，大模型不再只是“针对某个任务训练一个模型”，而是开始变成一种通用接口。

你可以给它描述任务、给几个例子，它就能尝试完成。这和过去为每个任务单独训练模型的方式很不一样。

## 第五阶段：ChatGPT 让大模型真正进入普通用户视野

ChatGPT 的影响不只是模型能力本身，还在于交互方式。

以前很多 AI 能力藏在论文、API、业务系统里，普通人很难直接感受到。ChatGPT 把这种能力包装成了对话界面，让每个人都可以用自然语言调用模型。

从知识结构上看，ChatGPT 让我意识到一件事：

> 大模型不只是一个模型，也是一种新的交互入口。

## 第六阶段：多模态和推理能力变得更重要

GPT-4 被 OpenAI 描述为可以接受图像和文本输入、输出文本的大型多模态模型。到了 GPT-4o，OpenAI 又强调它可以在文本、音频和视觉之间进行更自然的实时交互。

与此同时，推理能力、代码能力、数学能力、长上下文能力也变成模型竞争的重要方向。

这时候，大模型的发展不再只是“参数越大越好”，而是开始分化成几条路线：

```text
更强的通用能力
更低的推理成本
更长的上下文
更好的多模态交互
更强的推理和工具使用能力
```

## 第七阶段：DeepSeek 这类模型让“效率”变成焦点

DeepSeek-V3 这类模型让我注意到另一条主线：架构效率。

如果只是把模型做大，成本会非常高。于是现代模型会在很多地方做优化，比如：

- 用 MoE 让总参数很大，但每个 Token 只激活一部分参数
- 用 MLA 等注意力优化减少 KV Cache 成本
- 用更精细的训练和并行策略降低训练成本

这说明现代大模型竞争不只是“谁更大”，还包括：

```text
谁能用更低成本训练
谁能用更低成本推理
谁能在长上下文下保持效率
谁能把架构和工程结合得更好
```

## 我现在形成的时间线

```text
2012 左右：深度学习在视觉任务中爆发
2017：Transformer 出现，成为后续大模型底座
2018：BERT / GPT 让预训练范式成熟
2019：GPT-2 展示更强的生成能力
2020：GPT-3 展示规模化和少样本能力
2022：ChatGPT 让对话式大模型出圈
2023：GPT-4 推动多模态能力进入主流讨论
2024：GPT-4o 强调文本、音频、视觉的更自然交互
2024 之后：DeepSeek-V3 等模型让 MoE、注意力优化、训练效率受到更多关注
```

## 容易误解的地方

第一，不要把发展史理解成简单的模型榜单。真正重要的是范式变化。

第二，不要把“大模型发展”只理解成参数变大。规模很重要，但架构、数据、训练方法、对齐方法、推理系统同样重要。

第三，不要把多模态理解成“模型一定会画图”。多模态首先指模型能够处理不同类型的信息输入和输出。

## 这一篇我真正理解了什么

如果以后我忘了大模型的发展脉络，我只需要记住这条线：

```text
Transformer 提供架构底座
预训练提供学习范式
规模化带来通用能力
对话产品改变交互方式
多模态扩展输入输出边界
MoE 和注意力优化降低大模型成本
```
